# Studio Ghibli · Porco Rosso（吉卜力 · 红猪侠）主题皮肤

宫崎骏 1992 年经典动画《红猪》主题皮肤：萨伏亚 S.21 迎着晚霞破空飞行的绝美画面，搭配亚得里亚海炽红与蔚蓝复古航空调色板，内置久石让《归去不可得的日子》钢琴原声。
